# drafts/ — Your Research Ideas

This folder contains your personal draft YAML files for the FCT Proposal Engine.

## Convention

| File | Git-tracked? | Purpose |
|------|:---:|---------|
| `example_idea.yaml` | Yes | Template — copy this to start a new draft |
| Everything else | No | Your personal drafts — local only |

## How to start
```bash
cp example_idea.yaml my_project.yaml
nano my_project.yaml
```

Your personal YAML files are automatically excluded from Git via `.gitignore`.
They will never be pushed to GitHub, so your research ideas remain private.
